Goal: Create a centralized theming system in HtmlInfographicStrategy.ts to allow for cohesive "Skinning" of all templates.

1. Create the Theme Library:

    Define a constant THEME_LIBRARY in the strategy. Each theme should include:

        primary_accent: Hex code.

        background_main: Hex code (or gradient string).

        text_main: Hex code.

        font_family: Google Font URL and name.

        image_style_suffix: A short string to append to image prompts (e.g., "volumetric lighting, neon highlights").

2. Update the Art Director:

    Update generateBlueprint. Gemini must now choose a theme_id from the library that best fits the subject matter.

    Constraint: Gemini should no longer generate random hex codes; it must strictly use the IDs from our THEME_LIBRARY.

3. Implementation (JSDOM):

    In performGeneration, find the <style> tag in the template.

    Inject the theme's CSS variables into a :root selector:
    CSS

    :root {
      --primary: ${theme.primary_accent};
      --bg-page: ${theme.background_main};
      --text-color: ${theme.text_main};
      --font-main: '${theme.font_name}';
    }

    Ensure the templates (Hub, Step Stone, etc.) use these variables (e.g., background: var(--bg-page)).

4. The "Vibe Check" E2E Test:

    Create scripts/test-themed-generation.ts.

    Topic: "The Future of Quantum Computing."

    Requirement: The agent must detect a "Tech" theme, apply cyber_neon, and generate images that reflect that neon/dark aesthetic.

How this will be validated:

    Visually inspect the final PNG.

    Success Criteria: Does the background color, the glow on the lines, and the lighting in the AI-generated icons all match the same palette?
